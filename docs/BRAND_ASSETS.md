# MeterSift brand assets

The visual identity is built around an **open signal sieve**: three meter-profile traces enter the aperture; the middle trace continues through the normal path and branches into a distinct amber review lane. The mark communicates screening and controlled routing, not a verdict.

## Core palette

| Token | Hex | Use |
|---|---|---|
| Ink | `#182C31` | Primary wordmark, frame, dark surfaces |
| Signal Mint | `#70E4CE` | Incoming signal and ordinary path |
| Review Amber | `#E9B46B` | Exception branch and review state |
| Paper | `#F4F3EF` | Light backgrounds and contrast |

## Assets

- `experience/public/brand/metersift-mark.svg` — transparent standalone vector mark.
- `experience/public/brand/metersift-lockup.svg` — horizontal wordmark and mark.
- `experience/public/brand/metersift-app-icon.svg` — square dark app icon.
- `experience/public/brand/metersift-social-avatar.svg` — circular-crop-safe social avatar.
- `experience/public/favicon.svg` — compact browser favicon.

## Usage

- Use the horizontal lockup for documents and marketing placements with sufficient width.
- Use the standalone mark for compact navigation, favicons and app surfaces.
- Keep the amber branch visible; it is the identity's exception/review cue.
- Do not rotate, stretch, redraw, add gradients, or substitute generic shield, bolt, robot, brain or sparkle symbols.
- Maintain clear space around the mark of at least one stroke-width on all sides.
- The application uses the same vector mark with a live HTML wordmark so its typography follows the product's loaded Space Grotesk typeface.
